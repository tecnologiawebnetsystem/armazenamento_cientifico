GUIA DE ACESSO AO BANCO NEON
============================

Este arquivo NÃO contém credenciais reais.
As variáveis DATABASE_URL e demais credenciais devem permanecer no ambiente da Vercel/v0 ou em backend/.env local, que não deve ser versionado.

PROJETO
-------
NEON_PROJECT_ID=${NEON_PROJECT_ID}
Banco: ${PGDATABASE:-neondb}
Host: ${PGHOST}
Usuário: ${PGUSER}

CONFIGURAÇÃO DO BACKEND
-----------------------
DATABASE_ENGINE=postgresql
DATABASE_URL=<usar a variável DATABASE_URL fornecida pela integração Neon>
SEED_DATABASE=false
ENVIRONMENT=production
COOKIE_SECURE=true

CONEXÃO COM SSL
---------------
A conexão Neon deve usar SSL. Para ferramentas compatíveis com libpq, utilize:
sslmode=require

EXEMPLOS
--------

1) Backend Python:
   DATABASE_ENGINE=postgresql
   DATABASE_URL=postgresql://...Neon...?sslmode=require

2) psql:
   psql "$DATABASE_URL"

3) Aplicar schema:
   psql "$DATABASE_URL" -f backend/database/postgresql-schema.sql

4) Conferir tabelas:
   SELECT table_schema, table_name
   FROM information_schema.tables
   WHERE table_schema IN ('public', 'neon_auth')
   ORDER BY table_schema, table_name;

SEGURANÇA
---------
- Nunca colocar senha, token ou URL completa com senha neste arquivo.
- Nunca fazer commit de backend/.env, .env.local ou arquivos com credenciais.
- Use DATABASE_URL para a aplicação e DATABASE_URL_UNPOOLED apenas quando uma operação exigir conexão direta.
- As tabelas da aplicação ficam em public; as tabelas gerenciadas de autenticação ficam em neon_auth.

ALTERNAR ENTRE BANCOS
---------------------
SQLite:
   DATABASE_ENGINE=sqlite
   DATABASE_URL=sqlite+aiosqlite:///./data/sigac.db

PostgreSQL/Neon:
   DATABASE_ENGINE=postgresql
   DATABASE_URL=<URL Neon com SSL>

A alteração deve ser feita somente no .env ativo.
