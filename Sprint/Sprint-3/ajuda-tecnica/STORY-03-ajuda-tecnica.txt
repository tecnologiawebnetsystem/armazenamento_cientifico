------------------------------------------------------------------------------------
2) O QUE CRIAR / EXEMPLO DE CÓDIGO
------------------------------------------------------------------------------------
    def require_permission(perm: str):
        def _dep(user = Depends(get_current_user)):
            if user is None:
                raise HTTPException(401)
            if not has_permission(user, perm):
                audit_log(user, "ACESSO_NEGADO", perm)
                raise HTTPException(403)
            return user
        return _dep

    # uso no endpoint:
    @router.post("/projects", dependencies=[Depends(require_permission("projects.write"))])

- Testes (pytest) em back-end/tests/: permitido (200), sem permissão (403),
  sem sessão (401) para pelo menos 2 endpoints representativos.
