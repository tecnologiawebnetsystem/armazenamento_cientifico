  AJUDA TÉCNICA / REFINAMENTO

Trilha.....: Back-end
Objetivo...: Cada endpoint sensível exige perfil/permissão; sem sessão -> 401,
             autenticado sem permissão -> 403. Verificação no servidor.

------------------------------------------------------------------------------------

------------------------------------------------------------------------------------

    Núcleo de autorização (leitura da sessão/perfil).
    -> REFINAR: expor dependência `require_permission("x.y")` que valida a
       permissão exigida contra as permissões efetivas do usuário.
- back-end/app/api/dependencies.py
    Dependências FastAPI (get_current_user / get_session).
    -> Base para as dependências de autorização por rota.
- back-end/app/common/guards/__init__.py
    Local sugerido para guards reutilizáveis (Depends) por perfil/permissão.
- back-end/app/core/exceptions.py
    -> Garantir 401 (sem sessão) e 403 (sem permissão) distintos.
- back-end/app/core/audit.py  +  back-end/app/modules/audit/*
    -> Registrar tentativas negadas na trilha de auditoria.
- Controllers dos módulos (aplicar a dependência):
    back-end/app/modules/projects/controller.py
    back-end/app/modules/users/... , files/controller.py, audit/controller.py

------------------------------------------------------------------------------------
2) O QUE CRIAR
------------------------------------------------------------------------------------
- Dependência de autorização, ex.:
    def require_permission(perm: str):
        def _dep(user = Depends(get_current_user)):
            if user is None: raise HTTPException(401)
            if not has_permission(user, perm):
                audit_log(user, "ACESSO_NEGADO", perm)   # trilha de auditoria
                raise HTTPException(403)
            return user
        return _dep
  Uso no endpoint:  Depends(require_permission("projects.write"))
- Testes unitários (pytest) em back-end/tests/ cobrindo:
    * acesso permitido (200);
    * autenticado sem permissão (403);
    * sem sessão (401);
  para pelo menos 2 endpoints representativos.
