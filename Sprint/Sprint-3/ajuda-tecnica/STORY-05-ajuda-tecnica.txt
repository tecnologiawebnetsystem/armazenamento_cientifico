2) O QUE CRIAR
------------------------------------------------------------------------------------
- Util safeNext(next: string): string em lib/utils.ts:
    aceitar apenas caminhos internos que começam com "/" e não "//" nem URL
    absoluta -> previne open redirect.

------------------------------------------------------------------------------------
3) EXEMPLO DE CÓDIGO
------------------------------------------------------------------------------------
    // safeNext
    export function safeNext(next?: string) {
      if (!next || !next.startsWith("/") || next.startsWith("//")) return "/dashboard"
      return next
    }
    // interceptor 401
    if (res.status === 401 && !location.pathname.startsWith("/login")) {
      location.assign(`/login?next=${encodeURIComponent(location.pathname)}`)
    }

- Logout -> não consegue mais abrir rota interna; volta a /login.
- next=//evil.com ou http://... -> ignorado (cai em /dashboard).
