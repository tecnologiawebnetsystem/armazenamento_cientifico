  AJUDA TÉCNICA / REFINAMENTO

Trilha.....: Front-end
Pontuação..: 3
Depende de.: STORY-02 (endpoint de sessão)
Habilita...: STORY-06
Objetivo...: Bloquear rotas internas até a sessão ser verificada, sem flash de
             conteúdo protegido. (O tratamento de 401/logout é a STORY-05.)

------------------------------------------------------------------------------------
1) ONDE MEXER NO CÓDIGO (arquivos existentes)
------------------------------------------------------------------------------------
- app/(app)/layout.tsx
    Melhor ponto para o guard: verificar sessão antes de renderizar o conteúdo.
    -> Exibir carregamento enquanto verifica (evitar flash).
- hooks/use-session.ts
    Hook que busca a sessão (GET /api/auth/session via SWR).
    -> Expor { user, isLoading, isError }.
- components/petrobras-loading.tsx
    Reaproveitar para o estado "verificando sessão...".

------------------------------------------------------------------------------------
2) O QUE CRIAR (se necessário)
------------------------------------------------------------------------------------
- Componente RequireSession (wrapper) que:
    * enquanto isLoading -> mostra loading;
    * sem user -> redireciona a /login?next=<rota-atual>;
    * com user -> renderiza children.

------------------------------------------------------------------------------------
3) EXEMPLO DE CÓDIGO
------------------------------------------------------------------------------------
    const { user, isLoading } = useSession()
    if (isLoading) return <PetrobrasLoading />
    if (!user) { router.replace(`/login?next=${encodeURIComponent(pathname)}`); return null }
    return <>{children}</>

------------------------------------------------------------------------------------
4) BANCO DE DADOS
------------------------------------------------------------------------------------
- Nenhuma alteração. Consome o endpoint de sessão da STORY-02.

------------------------------------------------------------------------------------
5) COMO VALIDAR
------------------------------------------------------------------------------------
- Deslogado acessando rota interna -> vai a /login?next=... (sem flash).
- Logado -> conteúdo renderiza após loading curto.
- Recarregar rota interna logado -> não pisca conteúdo antes da verificação.
