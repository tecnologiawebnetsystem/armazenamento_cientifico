4. COMO VISUALIZAR OS REGISTROS COM SEGURANÇA

Use consultas somente leitura no Neon, sempre selecionando apenas as colunas necessárias:

SELECT id, email, name FROM users ORDER BY id;
SELECT id, name, status FROM projects ORDER BY id;
SELECT id, action, entity, created_at FROM activity_logs ORDER BY created_at DESC;
SELECT file_id, user_id, level FROM file_permissions ORDER BY file_id;

Não executar SELECT * nas tabelas users, sessions ou qualquer tabela que contenha tokens, credenciais ou dados pessoais.

5. SELEÇÃO DO BANCO LOCAL

SQLite:
DATABASE_ENGINE=sqlite
DATABASE_URL_SQLITE=sqlite+aiosqlite:///./data/sigac.db

Neon/PostgreSQL:
DATABASE_ENGINE=postgresql
DATABASE_URL_POSTGRESQL=<usar a DATABASE_URL fornecida pela integração Neon>

O backend escolhe a URL com base em DATABASE_ENGINE. Nenhuma migração Alembic repetida é necessária para a carga já realizada no Neon.
